# shiwake

指定フォルダ内のファイルを、拡張子ごとのフォルダに自動で振り分ける Bash スクリプトです。

## 特長

- 移動元フォルダ(`IF_DIR`)直下のファイルを、`DATA_DIR/拡張子名/` に移動します
- 拡張子名のフォルダがなければ自動で作成します
- 移動元と移動先のフォルダは設定ファイルで変更できます
- 移動元フォルダ内のサブフォルダとその中身には何もしません

## フォルダ構成

```
.
├── shiwake.sh      # スクリプト本体
├── shiwake.conf    # 設定ファイル
├── dock/           # 移動元フォルダ(既定)
└── storage/        # 移動先フォルダ(既定。なければ自動作成)
```

## 使い方

1. `shiwake.sh` と `shiwake.conf` を同じフォルダに置きます
2. 移動元フォルダ(既定は `dock`)を作成し、振り分けたいファイルを入れます
3. 実行権限を付けて、スクリプトを実行します

```bash
chmod +x shiwake.sh
./shiwake.sh
```

### 実行例

実行前:

```
dock/
├── photo.jpg
├── report.pdf
├── memo.txt
└── archive/        # フォルダは対象外
    └── old.txt
```

実行後:

```
dock/
└── archive/        # そのまま残る
    └── old.txt
storage/
├── jpg/photo.jpg
├── pdf/report.pdf
└── txt/memo.txt
```

## 設定

`shiwake.conf` で移動元と移動先を変更できます。

```
IF_DIR=dock
DATA_DIR=storage
```

| 項目 | 説明 | 既定値 |
| --- | --- | --- |
| `IF_DIR` | 移動元フォルダ。存在しない場合はエラーで終了します | `dock` |
| `DATA_DIR` | 移動先フォルダ。存在しない場合は自動で作成します | `storage` |

- 相対パスは、`shiwake.sh` のあるフォルダが基準になります
- 絶対パス(例: `/home/user/storage`)も指定できます
- `#` で始まる行はコメントとして無視されます
- 設定ファイルがない場合や値が空の場合は、既定値を使います
- 設定ファイルは `source` で読み込まず、値だけを取り出します。ファイルに書かれたコマンドは実行されません

## 動作仕様

- 移動の対象は、`IF_DIR` 直下のファイルのみです。サブフォルダとその中身は移動しません
- 拡張子は、ファイル名の最後のドット以降で判定します(例: `a.tar.gz` は `gz`)
- 拡張子の大文字・小文字は区別します(`.JPG` と `.jpg` は別フォルダになります)
- 拡張子のないファイルや、`.gitignore` のようにドットで始まるだけのファイルは移動せず、スキップします
- 移動先に同名のファイルがある場合は、上書きせずにスキップします

## 動作環境

- Bash 4 以降の `find` と `mv` が使える Linux / macOS 環境
- Windowsの場合、Git for Windows v2.56.0 で動作確認済み
