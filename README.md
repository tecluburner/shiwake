# shiwake

指定フォルダ内のファイルを、拡張子ごとのフォルダに自動で振り分ける Bash スクリプトです。

## 特長

- 移動元フォルダ(`dock`)直下のファイルを、`storage/拡張子名/` に移動します
- 拡張子名のフォルダがなければ自動で作成します
- 移動元と移動先のフォルダは設定ファイルで変更できます
- 移動元フォルダ内のサブフォルダとその中身には何もしません

## フォルダ構成

```
.
├── shiwake.sh      # スクリプト本体
├── dock/           # 移動元フォルダ
└── storage/        # 移動先フォルダ
```

## 使い方

1. 移動元フォルダ(`dock`)に振り分けたいファイルを入れます
2. 実行権限を付けて、スクリプトを実行します

```bash
chmod +x shiwake.sh
./shiwake.sh
```

### 実行例

実行前:

```
dock/
├── photo.jpg
├── report.pdf
├── memo.txt
└── archive/        # フォルダは対象外
    └── old.txt
```

実行後:

```
dock/
└── archive/        # そのまま残る
    └── old.txt
storage/
├── jpg/photo.jpg
├── pdf/report.pdf
└── txt/memo.txt
```

## 動作仕様

- 移動の対象は、`dock` 直下のファイルのみです。サブフォルダとその中身は移動しません
- 拡張子は、ファイル名の最後のドット以降で判定します(例: `a.tar.gz` は `gz`)
- 拡張子の大文字・小文字は区別します(`.JPG` と `.jpg` は別フォルダになります)
- 拡張子のないファイルや、`.gitignore` のようにドットで始まるだけのファイルは移動せず、スキップします
- 移動先に同名のファイルがある場合は、上書きせずにスキップします

## 動作環境

- Bash 4 以降の `find` と `mv` が使える Linux / macOS 環境
- Windowsの場合、Git for Windows v2.56.0 で動作確認済み
